# Changelog

All notable changes to e-app are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Versions are git tags (`vX.Y.Z`) cut by the Release workflow; the canonical,
continuous log lives in the [GitHub releases](https://github.com/damvolkov/e-app/releases)
notes (generated from the merged PR titles — write them as `feat:`, `fix:`,
`docs:`...). This file is reserved for milestone summaries only, so it can
never silently drift from reality.
